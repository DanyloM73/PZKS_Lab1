# Лабораторна робота №1 з дисципліни «Програмне забезпечення комп’ютерних систем»

Консольна програма мовою Kotlin, що виконує лексичний і синтаксичний аналіз арифметичних виразів. Вона розпізнає числа, змінні, оператори, дужки та математичні функції, а в разі помилки показує її тип і точне місце у введеному виразі.

## Системні вимоги

- 64-бітна операційна система Windows, macOS або Linux;
- Java 21 або новіша версія;

## Завантаження

1. Відкрийте [останній реліз програми](https://github.com/DanyloM73/PZKS_Lab1/releases/latest).
2. У розділі **Assets** завантажте файл `PZKS_Lab1-1.0.1.zip` та розпакуйте його.
3. Виконайте інструкцію для своєї операційної системи.

## Встановлення та запуск у Windows

Відкрийте PowerShell і запустіть програму:

```powershell
& "$HOME\Downloads\PZKS_Lab1-1.0.1\bin\PZKS_Lab1.bat"
```

Якщо програма знаходиться в іншій папці, замініть шлях у команді на фактичний.

## Встановлення та запуск у macOS і Linux

Відкрийте термінал і перейдіть до папки програми:

```bash
cd ~/Downloads/PZKS_Lab1-1.0.1
```

Надайте файлу дозвіл на виконання (якщо потрібно):

```bash
chmod +x bin/PZKS_Lab1
```

Запустіть програму:

```bash
./bin/PZKS_Lab1
```

## Використання

Після запуску введіть арифметичний вираз і натисніть Enter:

```text
sqrt(abs(-4)) + pow(2, 3)
```

Програма підтримує:

- числа та змінні;
- оператори `+`, `-`, `*`, `/`;
- унарні оператори `+` і `-`;
- круглі дужки;
- функції `sin`, `cos`, `tan`, `ctg`, `sqrt`, `abs`, `round`, `ln`, `log10`, `pow`, `min` і `max`.

Додаткові команди:

- `:functions` — показати перелік доступних функцій;
- `:exit` — завершити роботу програми.
